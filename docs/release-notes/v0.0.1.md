NAM-X 0.0.1 is the first update after the initial release: it now looks like a native app
on whatever desktop it runs on, the tempo and tuner fields are standard spin boxes, and
presets no longer carry your interface's input and output levels.

## What changed

- **Native look.** NAM-X follows your desktop's widget style instead of forcing its own:
  Union or Breeze on KDE Plasma, Windows 11 on Windows, whatever `-style` says. A forced
  Dark, Light or Custom theme, and the AppImage, use Qt's Fusion style dressed to match
  Plasma's: menus, buttons, check boxes, spin boxes, lists, tabs, scroll bars, tooltips
  and keyboard focus all drawn the way KDE draws them. Menus and dialog buttons show the
  desktop's icons, and the AppImage can now draw SVG icon themes (Breeze, Adwaita…).
- **Text follows the system font.** The rack, library and status bar size themselves to
  the font you have set, instead of 9 pt.
- **Three crashes when switching themes while running** are fixed.
- **Presets** no longer save or change the Input and Output knobs or the output limiter:
  they belong to your interface and speakers, not to a sound. A preset with a Sync
  switch on now saves the tempo too, so its delays and modulation come back as saved.
- **Tempo and tuner reference fields** are the desktop's own spin boxes: arrows, scroll
  wheel (Shift for fine steps), or type a value.
- **Tempo bar:** changing the time signature no longer shifts the controls beside it.
- **Tuner:** the sharp sign is drawn as bold as the note, so C♯ and F♯ read at a glance.
- **Renames:** the Dynamic Wah card is now "Wah", the Transpose's Continuous switch is
  "Fine" (presets and MIDI mappings are unaffected), and the settings window is
  Settings → Configure NAM-X… (Ctrl+Shift+,), as on KDE.

## Downloads

- **Linux:** the AppImage below (`chmod +x` it and run it). It uses your system's JACK or
  PipeWire and needs glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40 and up).
- **Windows:** the installer `namx-0.0.1-windows-x64-setup.exe`, or the portable
  `namx-0.0.1-windows-x64.zip` (unzip, run `namx.exe`). Both are unsigned, so
  SmartScreen warns about an unknown publisher.
- **Source:** the tarball below; build instructions are in `BUILD.md`.

The prebuilt binaries need an x86-64 CPU with AVX2 and FMA (Intel 2013+, AMD 2015+).

## Known limitations

- No ASIO on Windows, no macOS build, no DAW plugin.
- Mono models only (one input, one output).
- No distribution packages yet; on Linux it's the AppImage or a source build.
