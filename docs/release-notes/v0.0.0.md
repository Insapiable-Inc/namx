The first public release of NAM-X: a Linux-first, standalone, native Qt 6 app for
Neural Amp Modeler, with a built-in stereo effects chain, tuner, metronome, MIDI support
and other goodies. No DAW, no plugin host, no payment, no activation, no telemetry.

## What's in it

- **The amp:** any NAM model (WaveNet A1/A2 including slimmable, LSTM, ConvNet, Linear;
  file versions 0.5 to 0.7), run by NeuralAmpModelerCore at the model's own sample rate.
- **The cabinet:** any mono WAV impulse response, with no added latency.
- **15 effects,** reorderable by dragging (the amp too): Tuner, Transpose, Noise Gate, Compressor,
  Dynamic Wah, Flanger, Phaser (an MXR Phase 90 circuit model), Overdrive (a Tube Screamer
  circuit model), Volume Pedal, Equalizer, Chorus, Tremolo, Delay, Reverb and the
  Cabinet, plus an optional output limiter. Delay time, modulation rates and the reverb
  pre-delay can sync to the tempo.
- **Tempo and metronome** with tap tempo, accents and count-in.
- **MIDI:** map any knob or switch, plus the tuner, the metronome, preset slots and
  library browsing, to a footswitch or an expression pedal; MIDI Learn; MIDI clock.
- **Library panel** for your models, IRs and presets, with search, favorites and recents.
- **Presets** as plain JSON files, quick slots 1–8, A/B compare, and eight starter presets.

## Downloads

- **Linux:** the AppImage below, or Flathub (`io.github.Insapiable_Inc.namx`). Both use
  your system's JACK or PipeWire.
- **Windows:** `namx-0.0.0-windows-x64.zip` (unzip, run `namx.exe`).
- **Source:** the tarball below; build instructions are in `BUILD.md`.

The prebuilt binaries need an x86-64 CPU with AVX2 and FMA (Intel 2013+, AMD 2015+).

## Known limitations

- **Windows is untested on real hardware.** The WASAPI backend builds in CI but has not
  been run on a Windows machine yet, and exclusive mode is new. Reports welcome.
- No ASIO on Windows, no macOS build, no DAW plugin.
- Mono models only (one input, one output).
- From the Flatpak, a classic `jackd` setup (without PipeWire) is awkward; use the
  AppImage or a source build there.
