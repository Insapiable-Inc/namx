# TONE3000 brand assets

`tone3000-logo.png` (full logo) and `t3k-mark.png` (compact mark) come from the official
"TONE3000 Logos" pack published on <https://www.tone3000.com/api> for API integrations.
They are TONE3000's trademarks, used here under their API design requirements: the full
logo appears at entry points (partnership splash, list header) before the compact mark
is shown in buttons and as the origin marker on the Amplifier/Cabinet rows. Do not
recolor, restyle or reuse them elsewhere.
